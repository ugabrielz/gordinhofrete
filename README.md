# Gordinho Frete — Landing Page

Landing page estática inspirada na identidade visual da arte enviada e na estrutura usada no site da Recicladora Martins.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — todo o visual, responsividade e animações
- `script.js` — loader, menu mobile, navbar que some ao rolar, reveal e parallax
- `assets/gordinho-frete-referencia.jpeg` — arte fornecida como referência

## Identidade visual usada

- Azul marinho: `#0b1f3a`
- Laranja: `#f04b23`
- Amarelo: `#ffc928`
- Fundo claro: `#f6f1e8`
- Fontes: Archivo Black + Inter

## Comportamentos

- Loader inicial com a sigla GF
- Navbar fixa e escondendo ao rolar para baixo
- Menu mobile
- Animações de entrada por scroll
- Efeito parallax no hero e na seção visual
- Faixa animada de serviços
- Botão flutuante do WhatsApp
- CTAs já apontando para o número da arte

## Como abrir

Basta abrir o `index.html` no navegador.

Para desenvolver no VS Code, é recomendado usar a extensão **Live Server**.

## Para publicar

Pode subir a pasta no GitHub e importar o repositório na Vercel. Como é uma landing page estática, não precisa de backend.
